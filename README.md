# Complete Portfolio Website (HTML/CSS/JS)

A complete, single-page portfolio template built with plain HTML, CSS, and JavaScript.

## Sections included
- Sticky header with responsive mobile navigation
- Hero with call-to-action buttons
- About section
- Skills section
- Featured projects cards
- Experience timeline
- Contact form UI
- Footer with social links

## Customize quickly
1. Update `index.html` with your name, bio, project details, and links.
2. Replace placeholder social profiles in the footer.
3. Adjust colors and spacing in `styles.css`.
4. Open `index.html` in a browser to preview.
